# Telegram-бот оповещений о рейде

Бот работает в паре с плагином **RaidAlert 2.3+** и меню **Menu 2.5+**.

## Как это работает

1. Игрок открывает `/menu`, в карточке «Уведомления о рейде» нажимает **TELEGRAM** и получает код.
2. Игрок подписывается на канал и отправляет код боту. Можно открыть ссылку `t.me/<бот>?start=<код>` из окна: тогда хватит нажать START.
3. Бот проверяет подписку. Если подписки нет, он показывает кнопки «Подписаться» и «Я подписался» и код не принимает.
4. Игровой сервер раз в 5 секунд забирает у бота введённые коды, проверяет их и отвечает. Бот пишет игроку «✅ Готово!» или «❌ Код не найден».
5. Во время рейда сервер присылает боту оповещение. Перед отправкой бот ещё раз проверяет подписку.
6. Если человек отписался, бот сразу снимает привязку, предупреждает его и сообщает серверу. Плагин тоже снимает привязку и пишет игроку в чат. Дополнительно бот раз в 6 часов сверяет подписку у всех привязанных.

Сервер сам обращается к боту, бот к серверу не обращается никогда. Поэтому игровому серверу не нужен открытый порт, а бот может жить на любом хостинге, где открыт доступ к Telegram.

## Установка

Нужен **Node.js 18 или новее**. Сторонних пакетов нет, `npm install` не требуется.

1. Создай бота у [@BotFather](https://t.me/BotFather) командой `/newbot` и скопируй токен.
2. Добавь бота **администратором** своего канала. Права можно все выключить: роль администратора нужна, только чтобы бот видел подписчиков.
3. Скопируй `config.example.json` в `config.json` и заполни его:

| Поле | Что писать |
|---|---|
| `botToken` | токен от BotFather |
| `channel.id` | `@username` канала или числовой ID приватного канала (`-100…`) |
| `channel.url` | ссылка на канал для кнопки «Подписаться» (для приватного канала укажи ссылку-приглашение) |
| `channel.title` | как канал называется в сообщениях (если оставить пусто, бот возьмёт название из Telegram) |
| `serverName` | название сервера в оповещении (пусто означает имя сервера из игры) |
| `api.port` | порт, на котором бот принимает запросы от сервера |
| `api.secret` | длинная случайная строка, та же, что в конфиге плагина |
| `api.allowedIps` | IP игрового сервера, например `["185.1.2.3"]`. Остальным бот откажет. Пусто означает без ограничения по IP |
| `api.trustProxy` | `true`, только если бот стоит за обратным прокси (nginx, PaaS) и IP нужно брать из `X-Forwarded-For` |
| `recheckHours` | как часто сверять подписку у всех привязанных (`0` выключает сверку) |
| `texts` | сюда можно переопределить любой текст бота (ключи смотри в `bot.js`, объект `texts`) |

Случайную строку для `secret` можно получить так: `node -e "console.log(require('crypto').randomBytes(24).toString('hex'))"`

4. Запусти бота:

```bash
node bot.js
```

Чтобы бот работал постоянно и поднимался после перезагрузки, запускай его через pm2:

```bash
npm i -g pm2
pm2 start bot.js --name raidalert-tg
pm2 save && pm2 startup
```

Токен, секрет и порт можно передать и переменными окружения: `BOT_TOKEN`, `API_SECRET`, `PORT`, `CHANNEL_ID`, `CHANNEL_URL`. Это удобно на хостингах вроде Railway или Render.

5. Открой порт `api.port` в фаерволе хостинга (желательно только для IP игрового сервера).
   Работу бота можно проверить в браузере: `http://IP_БОТА:8085/health`.

## Настройка плагина

В `oxide/config/RaidAlert.json`, раздел `Telegram`:

```json
"Telegram": {
  "Включить Telegram": true,
  "Адрес бота (как в его config.json: http://IP:порт)": "http://IP_БОТА:8085",
  "Секретный ключ (api.secret в config.json бота)": "та_же_строка_что_в_боте",
  "Отправлять оповещения о рейде в Telegram": true,
  "Как часто забирать у бота привязки и отписки, сек": 5.0,
  ...
}
```

После `oxide.reload RaidAlert` в консоли должна появиться строка «Связь с ботом Telegram установлена (@имя_бота)».

## Команды бота

- `/start`: инструкция, а со ссылкой `?start=КОД` сразу принимает код
- `/status`: показывает, привязан ли аккаунт
- `/unlink`: отвязать Telegram (в игре привязка снимется тоже)
- любое сообщение с кодом: привязка

## Файлы

- `data.json`: привязки и очередь событий для сервера. Его стоит иногда копировать в бэкап. Если файл потеряется, привязки в игре останутся, и бот восстановит их по первому оповещению.
- В игре привязки хранятся в `oxide/data/RaidAlert/players.json` (поле `tg`).
